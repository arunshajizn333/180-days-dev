Q8. Parallel execution

Now rewrite Q7 so all three timers start at the same time.

Expected:

First  → 2s
Second → 1s
Third  → 1s

Total time should be approximately 2 seconds, not 4.

Use:

Promise.all()

const p1= new Promise ((res,rej)=>{
    setTimeout(function(){
        res("First")
    },2000)

})
const p2= new Promise ((res,rej)=>{
    setTimeout(function(){
        res("Second")
    },1000)

})
const p3= new Promise ((res,rej)=>{
    setTimeout(function(){
        res("Third")
    },1000)

})

const data=Promise.all([p1,p2,p3])
console.log(await data);
