Q13. Predict the output

const p1 = new Promise(resolve =>
    setTimeout(() => resolve("P1"), 3000)
);

const p2 = new Promise(resolve =>
    setTimeout(() => resolve("P2"), 1000)
);

const p3 = new Promise(resolve =>
    setTimeout(() => resolve("P3"), 2000)
);

Promise.all([p1, p2, p3])
    .then(result => console.log(result));

Questions:

When does it print? after 3s
What is the array? [P1,p2,p3]
Why isn't the array [P2, P3, P1]?because promise .all maintains the ordginal order of the input array,regardless of which promise resolve first


Q14. Promise.all() failure

const p1 = new Promise(resolve =>
    setTimeout(() => resolve("P1"), 3000)
);

const p2 = new Promise((resolve, reject) =>
    setTimeout(() => reject("P2 Failed"), 1000)
);

const p3 = new Promise(resolve =>
    setTimeout(() => resolve("P3"), 2000)
);

Promise.all([p1, p2, p3])
    .then(console.log)
    .catch(console.log);

Answer:

When does catch execute?immediatly when catch caughts reject
What happens to p1?its output will not be considered as promise.all only gives output if all are resolved and if any one of them fails whole output will not be printed only first catch will be printed
What happens to p3?its output will not be considered as promise.all only gives output if all are resolved and if any one of them fails whole output will not be printed only first catch will be printed
Why?its output will not be considered as promise.all only gives output if all are resolved and if any one of them fails whole output will not be printed only first catch will be printed
