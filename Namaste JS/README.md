# 🚀 Namaste JS: Functions Masterclass

A collection of core JavaScript function implementations and patterns built for daily coding practice.

## 📌 Features & Concepts Covered

1. **Pure Functions**: Deterministic calculations (`add`, `multiply`, `square`).
2. **Closures**: Encapsulation of state with `createCounter`.
3. **Higher-Order Functions**: Function decoration using `memoize`.
4. **Function Composition**: Pipeline function execution using `pipe`.
5. **Async / Await**: Asynchronous workflow handling with simulated promise-based requests (`fetchSimulatedData`).

## 🛠️ Usage

Run the program locally using Node.js:

```bash
node index.js
```
